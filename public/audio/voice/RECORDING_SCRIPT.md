# Пакет записи первого эпизода, версия 0.4

Готовых MP3 нет. Четырнадцать обязательных реплик Верити перечислены ниже; текст совпадает с src/story.js. Мысли героя остаются субтитрами и приведены отдельно для полноты сценария.

Голос: русский, дружелюбный, мультяшный, немного странный; самостоятельная актёрская трактовка без имитации оригинального актёра. Первые пять реплик — искренняя помощь. В коридоре тише, с осторожной паузой после «немного»; у дверей мягкая настойчивость, без злости и рычания.

Технически: MP3 mono, 44,1 или 48 кГц, 128–192 кбит/с; без музыки, реверберации, обрезанных согласных и длинных пустот в начале/конце. Предоставить чистый мастер WAV отдельно. Не добавлять искусственное замедление в запись: мягкий эффект подозрительного голоса уже предусмотрен проигрывателем. Для каждой записи сохранить имя исполнителя/сервиса и разрешение на использование в коммерческой игре.

## Мысли героя — без обязательной голосовой записи

- **treat**: Идеальный крем. Ни одного следа ножа. Даже запаха нет.
- **partyNote**: На карточке порядок: свеча, подарок, звезда. Нужно найти их знаки.
- **candleClue**: На подставке свечей выгравирована луна.
- **giftClue**: На подарке знак ромба.
- **starClue**: На основании украшения — звезда.
- **cakeEntry**: Ручка с этой стороны неподвижна.
- **cakeWrong**: Красный индикатор. Последовательность не подходит. Можно попробовать ещё раз.
- **wake**: Моя комната… Только тишина какая-то чужая.
- **drawerLocked**: Ящик заедает. На столе осталась записка: «Запасной предохранитель».
- **fuseAgain**: Предохранитель уже у меня.
- **panelEmpty**: Пустое гнездо. Не хватает предохранителя.
- **panelOn**: Электричество работает. Пора выходить.
- **locked**: Не открывается. Электрический замок обесточен.
- **exit**: Замок щёлкнул. Можно идти.
- **bed**: Одеяло ещё тёплое. Значит, я только что проснулся.
- **window**: За стеклом темно. Даже соседних окон не видно.
- **wardrobe**: Моя одежда. Всё на своих местах. Почти всё.
- **middle**: Гул не становится тише. Этот коридор длиннее, чем должен быть.

## Подключение

Добавить четырнадцать MP3 в public/audio/voice и сопоставить ключи .ogg из src/story.js с путями .mp3 в manifest.json (образец в README.md). После этого выполнить npm test и npm run build. При отсутствии или ошибке файла остаются субтитры. Рот получает амплитуду реальной записи, а без неё сохраняет эмоциональную улыбку. Реплики 08–14 относятся к комнате с тортом: радость, помощь, тревога, настойчивость, возвращение к спокойствию и ярость после кнопки. Ярость резкая, без клиппинга и без имитации чужого голоса.

Этот документ и recording-script.json обновляются командой node scripts/voice-script.mjs.
