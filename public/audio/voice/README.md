# Записи русского голоса Верити

**Готовой речевой озвучки в проекте нет.** Не найден инструмент генерации с подтверждёнными коммерческими правами. Нет клонирования актёра, платного API или синтеза речи в реальном времени. Система воспроизведения реализована; в настройках прямо указано отсутствие записей.

Добавьте собственные записи с необходимыми правами в этот каталог. Рекомендуются Ogg Vorbis или MP3, mono, 44,1/48 кГц, без перегруза. Для наибольшей совместимости с Safari используйте MP3: имя фактического файла задаётся в манифесте.

| --- | --- |
| audio/voice/01-hello.ogg | Привет! Я Верити. Не бойся, я помогу тебе выбраться. В ящике стола должен быть предохранитель. — дружелюбный |
| audio/voice/02-box.ogg | Спасибо, что выпустил меня. Теперь давай включим свет. — дружелюбный |
| audio/voice/03-fuse.ogg | Вот он! Поставь его в щиток рядом с дверью. Потом подними выключатель. — дружелюбный |

После добавления файлов заполните `manifest.json`, например:

```json
{
  "status": "ready",
  "files": {
    "audio/voice/01-hello.ogg": "audio/voice/01-hello.mp3",
    "audio/voice/06-corridor.ogg": "audio/voice/06-corridor.mp3"
  }
}
```

Ключи соответствуют `src/story.js`, значения — относительные пути в `public/`. Неперечисленные записи не запрашиваются, поэтому прототип не выдаёт серию 404. При ошибке загрузки остаются субтитры.

Голос имеет отдельную шину громкости. Подозрительный голос слегка замедляется и приглушается; разъярённый понижается, фильтруется и мягко искажается с ограниченным усилением. Дружелюбные записи воспроизводятся без изменения темпа. Субтитры появляются при начале диалога, остаются на время загрузки и звучания, исчезают через секунду после окончания. Новая реплика прерывает предыдущую. Пауза приостанавливает AudioContext вместе с репликой. При отсутствии записи текст держится рассчитанное время, а не изображает звучащий голос.
