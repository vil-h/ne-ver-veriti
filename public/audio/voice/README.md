# Русский голос Верити — 0.7

Готова 21 игровая MP3-реплика и 3 демонстрационных записи. 14 прежних реплик, 4 реплики сцены у ямы и 3 реплики ветки «Спасение». Точный текст, эмоция, длительность, RMS, пик и SHA-256 каждого файла — в manifest.json. Старые .ogg-ключи сохранены как идентификаторы; фактически загружаются MP3 mono 22,05 кГц / 80 кбит/с.

Голос: Piper 1.8.0, ru_RU-denis-medium, переобученная версия на базе rdh (CC0). Данные Denis — CC0, карточка сохранена в ../licenses/DENIS_MODEL_CARD.txt. Не использовать старый checkpoint Denis на базе lessac вместо этого. Модель и синтезатор используются только при сборке аудио и не включены в игру. См. ASSETS.md.

Обработка FFmpeg: высота +13% для дружелюбного, +5% для подозрительного, -21% для гневного; независимая коррекция темпа, фильтры, мягкое насыщение гневного голоса, нормализация до -20 LUFS с ограничением true peak -3 dB. Эмоции синтетические, не актёрская запись. Голос оригинального актёра не клонировался.

Громкость голоса регулируется отдельно. Анализатор сигнала управляет ртом. Пауза приостанавливает AudioContext; новая реплика останавливает предыдущую. Субтитры остаются до окончания записи плюс одна секунда. Ошибки загрузки оставляют текстовую реплику с конечной длительностью.

Воспроизводимый процесс: установить piper-tts==1.8.0 и imageio-ffmpeg==0.6.0 в отдельную Python-среду; скачать указанный checkpoint с его JSON; выполнить scripts/generate-voice.py MODEL.onnx WORKDIR (три образца), затем добавить --all. Режим --new добавляет только отсутствующие записи и сохраняет прежние файлы. Не требуется для игры или npm run build.

Сигнал и декодирование проверены автоматически, Web Audio воспроизведение и движение рта — в браузере. Субъективная оценка разборчивости и актёрской выразительности человеком не выполнена: среда агента не поддерживает прослушивание аудиовхода.
