# Происхождение материалов версии 0.3

Внешние модели, фотографии, текстуры, музыка и голосовые записи не скачивались.

| Материал | Источник / авторство | Условия |
| --- | --- | --- |
| Кровать, складки одеяла, подушки, мебельные фасады, шторы, коробка, мелкие детали | Созданы в рамках этого проекта; `src/polish.js` | Собственные процедурные материалы проекта, сторонней лицензии нет |
| Древесина, ткань, обои, ковёр, металл, карты нормалей | Генерируются кодом `src/materials.js` | Собственные процедурные материалы проекта |
| Потёки и пятна сырости | Генерируются кодом `src/polish.js` | Собственные процедурные материалы проекта |
| Геометрия шара, рисунок лица и анимации | Созданы в проекте; `src/verity.js` | Не скопированы из чужой модели или изображения; права на исходного персонажа рассматриваются отдельно |
| Гул, шум, шаги по дереву/ковру, стук, шорох, взаимодействия | Процедурный Web Audio; `src/audio.js` | Нет сторонних сэмплов, записей актёров или музыкальных произведений |
| Русский голос | Записей нет | Пакет для записи: `public/audio/voice/RECORDING_SCRIPT.md` |
| Babylon.js | Babylon.js contributors | Apache-2.0, файл лицензии установленного пакета `@babylonjs/core` |
| Vite | Vite contributors | MIT, файл лицензии установленного пакета `vite` |

Этот реестр фиксирует происхождение ассетов, но не выдаёт новую лицензию на проект целиком. Требование исходного дизайн-документа о правах на персонажа для коммерческого релиза сохраняется.
