# Проверка версии 0.4

Дата: 14 ноября 2026. Ветка: feature/cake-room. Предыдущий отчёт: TEST_REPORT_0.3.md.

## Автоматические проверки

18 тестов прошли, включая пять новых проверок: переход через красивую дверь, неверный/верный код и выход, доступность кнопки до/после решения, повторные действия, предупреждения и успокоение, чистое состояние нового запуска. Сохранены тесты вступления, столкновений, диалогов и атмосферных событий. Голосовые тесты используют имитацию аудио, не настоящие MP3.

Production-сборка Vite успешна: 574 модуля. Распакованный dist: 1 855 167 байт (1.86 МБ). ZIP проверен на целостность, index.html в корне. Относительная база ./ и workflow GitHub Pages сохранены: npm ci → npm test → npm run build → deploy.

## Браузер

Встроенный браузер Codex, WebGL 2, production-сборка по HTTP. Несколько раз вручную пройдены спальня → коробка → предохранитель → щиток → электричество → коридор → красивая дверь → комната с тортом. Проверены WASD, обзор стрелками, E, пауза, смена качества и перезапуск из точки продолжения с возвратом в спальню и повторным прохождением.

Проверены осмотр торта, видимые предметные подсказки, неверная попытка замка без блокировки, ввод правильных символов, открытие двери и переход к следующему эпизоду. Замок проверен также при 390×844: кнопки и сообщение об ошибке помещаются, символы переключаются.

У кнопки наблюдались обеспокоенная и настойчивая реплики. После отхода предупреждение сбрасывается и может запуститься снова; пятитисекундное успокоение отдельно покрыто тестом. Нажатие вызвало красный свет, падение украшений и стеновых панелей, сердитое лицо и растяжение силуэта Верити, затем экран «Начало погони». Это точка продолжения, не реализованная погоня и не финал.

Исправлены обнаруженные визуально пересветы и неудобный выбор открытой двери: у выхода теперь собственная интерактивная поверхность. Сохранены скриншоты комнаты, мобильного замка и начала разрушения в папке ../qa-0.4. На них присутствует диагностическая панель; обычный запуск её не показывает.

Диагностика на проверенных участках показывала 58–60 FPS при 1440×900 / high и около 60 FPS при 390×844. Это отдельные показания текущего компьютера, не тест слабого телефона и не длительный бенчмарк. Консоль проверенной вкладки не содержала ошибок или предупреждений; диагностическое поле error пустое.

## Звук и ассеты

Реальных голосовых файлов: 0. Подготовлены 14 реплик (семь новых для комнаты) в public/audio/voice/RECORDING_SCRIPT.md и recording-script.json. Пустой manifest не вызывает запросы отсутствующих записей; субтитры и эмоции работают. Для будущих MP3 сохранены синхронизация по окончанию записи, пауза и прерывание диалогов.

Тревога и окружение синтезируются Web Audio. Ошибок запуска не обнаружено; субъективный баланс звука и пространственность в наушниках человеком в этой проверке не оценивались. Все новые модели, надписи и анимации процедурные, сторонние ассеты не скачивались. Происхождение: ASSETS.md.

## Ограничения

Графика стилизованная, разрушение постановочное, без физического движка обломков. Превращение показано только в начале. Нет погони, дальнейших сюжетных комнат, ветки спасения, сохранения прогресса, Yandex SDK или рекламы. Сенсорная схема сохранена; физические телефоны, мультитач, Safari/iOS и захват мыши в этой итерации не проверялись. Выкладка на Pages проверяется отдельно после публикации этого коммита.
