# Проверка версии 0.7

20 ноября 2026. Ветка `feature/rescue-ending`. Предыдущий отчёт сохранён в `TEST_REPORT_0.6.md`.

## Реализовано

Железная дверь физически открывает проход из коридора в техническую комнату. Игрок входит сам; внутренний порог закрывает заслонку. После реплики Верити исчезает. Пазл с распределительным щитом, резервной цепью, вентиляцией и замком допускает исправление любых ошибок. Терминал содержит полный порядок действий, включая ограничение мощности резерва.

Мониторы показывают кадры реальных 3D-декораций: существующую спальню с необычного ракурса и скрытые двери/каркас за стеной. Это RenderTargetTexture, а не внешние изображения. Кадры обновляются при открытии двери, затем сохраняются, чтобы не рендерить дополнительные камеры постоянно. Один монитор неисправен. Голос пространственно размещён у вентиляции. После разблокировки замка фон замолкает; дверь открывается отдельным действием E, в проходе слышно тихое тиканье.

Ложное пробуждение использует прежнюю спальню с другим светом и без коробки. После подъёма камеры доступны свободное движение и обзор. Маленький молчаливый Верити находится на кровати. Финал требует взгляда на персонажа с проверкой направления и преграды; через 25 секунд ожидания доступен только тихий намёк. После обнаружения — поворот лица, расширение улыбки, затемнение и «ТЫ НЕ ПРОСНУЛСЯ». ID завершения `rescue-false-awakening`; новый эпизод не добавлен.

## Автоматические проверки

`npm test`: 35/35 успешно. Семь новых тестов проверяют переход без телепорта, однократное закрытие двери, последовательность interlock/резерв/нагрузка/замок, восстановимость всех семи достижимых комбинаций, сброс резерва, отсутствие финала по таймеру, непрерывное обнаружение и ID концовки. Прежние тесты состояний, погони, коллизий, гуманоидной модели и диалогов сохранены. Проверены тексты, файлы, SHA-256 и измерения сигнала всех 21 игровых MP3.

`npm run build`: успешно, 588 модулей. Основной JS около 105 КБ, Babylon около 1,76 МБ. Распакованная сборка: 2,965,712 байт. База `./`, клиентский стек и Pages workflow сохранены. QA-кнопки и инспектор существуют только в Vite DEV при `?qa=1`; production их не содержит.

## Браузерная проверка

Отдельный официальный Chromium 151, Playwright, WebGL 2. Ввод движения/поворота/взаимодействий — реальные клавиатурные события браузера. В сквозном прогоне состояние игры и координаты не подменялись: старт → коробка и речь → ящик → предохранитель → питание → дверь → весь коридор → «СПАСЕНИЕ» → самостоятельный вход → заслонка → терминал → мониторы → ошибочное включение резерва → исправление → голос из вентиляции → ошибка перегрузки → отключение вентиляции → разблокировка → ручное открытие → тёмный проход → утренняя спальня.

После пробуждения дополнительно ожидали 26 секунд, не глядя на кровать: игра осталась в `explore`, ID концовки отсутствовал. После поворота к Верити зафиксированы `reveal`, затем `ended` и правильный ID. Перезапуск очистил все состояния, вернул ночную спальню и позволил вновь открыть коробку с реальным голосом. Количество мешей оставалось 551; в комнате активны три источника света с учётом ambient, в утренней спальне — два. Ошибок JavaScript в завершённом сквозном прогоне нет.

Визуально просмотрены мониторы, техническая комната, утренняя спальня и Верити. Исправлена найденная при осмотре ошибка: белое свечение материала перекрывало изображение мониторов. После исправления видны спальня/коробка и скрытые двери. Во время разработки Vite один раз обновил кеш оптимизированных зависимостей и старый запрос shader-модуля не загрузился; после перезагрузки ошибка не воспроизводилась.

390×844, низкое качество и уменьшение движения: проверены утренняя сцена, обнаружение и концовка, возврат в меню, вход в техническую комнату экранной кнопкой, читаемость длинной инструкции. Указателем проверен экранный джойстик: координаты изменились с (2,10; 34,13) до (2,82; 34,61). Это эмуляция мобильного viewport на компьютере, не физический телефон. Часть проверок целевых сцен использовала DEV QA-кнопки и отдельно от полного прохождения.

Скриншоты и журналы находятся в `../qa-0.7`: technical-room.jpg, monitors.jpg, switchboard.jpg, unlocked.jpg, morning.jpg, verity-bed.jpg, ending.jpg, mobile-instruction.jpg, mobile-morning.jpg, mobile-verity.jpg, mobile-ending.jpg; checks.json и mobile-checks.json.

Отдельно проверены прежние сцены через DEV-контрольные точки: красная кнопка, гуманоид, физический переход в погоню, поимка и повтор; у ямы — разговор, явное доверие с предательством и прыжок к экрану продолжения. При первом прогоне вспомогательный маршрут пытался продолжить движение к старым координатам уже после перехода в погоню; исправлен тестовый сценарий. Один прогон у ямы был прерван перезагрузкой Vite после правки; отдельная повторная проверка без изменений кода прошла, ошибки JavaScript отсутствуют. Это не повторный полный забег по всем 216 метрам: маршрут дополнительно покрыт прежним автоматическим тестом.

Исправлено столкновение с исчезнувшей коробкой в утренней спальне. Браузер подтвердил свободный проход через её прежнее место; после перезапуска ночная коробка снова блокирует движение. Журнал collision-checks.json. Вспомогательные журналы regression-checks.json и pit-checks.json различают прерванную и завершённую проверки.

## Ограничения

Субъективная оценка речи и микса в наушниках не выполнена. Нет проверки физического телефона, iOS/Safari, мультитача и длительного нагрузочного профилирования; около 60 FPS в наблюдавшихся сценах относится только к тестовому компьютеру. Пространственные сцены и анимации процедурные, камеры наблюдения показывают сохранённые кадры. Постоянное сохранение открытых концовок не добавлено; ID предусмотрен в состоянии. Следующие эпизоды после замка и прыжка, реклама и Yandex Games SDK не добавлены. Права на персонажа для монетизации отдельно не проверялись.
