# Не верь Верити! — версия 0.4

Локальный браузерный WebGL-прототип: спальня, появление Верити, восстановление электричества, коридор и выбор двух дверей. Полностью клиентский проект на Babylon.js + Vite. Это не вся сюжетная игра.

[Играть в браузере](https://vil-h.github.io/ne-ver-veriti/)

## Что нового в 0.4

Красивая дверь ведёт в исследуемую праздничную комнату. Подсказки на предметах задают код из трёх символов; ошибка допускает повторную попытку, решение открывает выход. Красная кнопка вызывает предупреждения Верити, тревожный звук, красный свет, падение декораций и начало превращения. Оба пути заканчиваются честными точками продолжения; погоня не реализована.

## Полировка 0.3

Мягкая геометрия постели и складки ткани, детализированные мебель и коробка, шторы и ночной свет, карты нормалей материалов и потёки в коридоре. Плавное появление и поворот Верити, моргание, амплитудная анимация рта при подключении записей. Пространственный шум, редкие стуки и шорохи, разные шаги по дереву и ковру. Стартовая задача теперь предлагает осмотреться без прямого указания на коробку.

Материалы и права: [ASSETS.md](ASSETS.md). Полный пакет для записи: [RECORDING_SCRIPT.md](public/audio/voice/RECORDING_SCRIPT.md). **Готовых голосовых MP3 по-прежнему нет.**

## Запуск

Если папка `dist` уже собрана, на Mac игру можно запустить двойным щелчком по `Запустить игру.command`: используется Python 3, скачивать зависимости не нужно. Сервер работает только локально.

Для разработки нужен Node.js 22 LTS или новее и npm.

```sh
npm install
npm run dev
```

Откройте адрес, который выведет Vite, обычно http://127.0.0.1:5173.

```sh
npm test
npm run build
npm run preview
```

Сборка находится в `dist/`, пути относительные. Для ZIP упаковывайте **содержимое** `dist`, чтобы `index.html` находился в корне. Открывать игру следует через HTTP, не через `file://`. Для проверки с телефона в одной локальной сети: `npm run dev -- --host 0.0.0.0`, затем откройте IP компьютера и порт 5173. SDK, реклама, серверные сервисы и внешние CDN отсутствуют.

В данной среде обычные `node` и `npm` не были в PATH; использован встроенный Node.js Codex и локально установленный npm. Это особенность среды разработки, а не зависимость игры.

## Управление

- WASD — ходьба; мышь — обзор после клика по сцене. Если захват мыши недоступен, удерживайте кнопку мыши и тяните.
- Стрелки — альтернативный обзор с клавиатуры.
- E или кнопка под прицелом — действие. Нужно подойти ближе и посмотреть на предмет.
- Escape или «Пауза» — остановка игры. При возврате нажмите «Продолжить», затем при необходимости кликните по сцене.
- Телефон: джойстик слева, свайп по сцене для поворота камеры, кнопка действия под прицелом. Сенсорные элементы можно включить вручную в настройках.

В настройках есть общий звук, отдельные громкости окружения, эффектов и голоса, чувствительность, субтитры, уменьшение движения/мерцания, три уровня графики. На телефоне по умолчанию выбрано низкое качество. Параметры сохраняются в localStorage; игра работает и при недоступном хранилище.

## Что работает

Свободное перемещение на высоте глаз, столкновения со стенами и мебелью, raycast-взаимодействия на расстоянии до 2,55 м, коробка и крышка, парящий золотистый Верити с меняющимся лицом, стол/предохранитель/щиток, свет и открывающаяся дверь, непрерывная прогулка в коридор, тёмные боковые ответвления, две двери, комната с тортом и разные точки продолжения. Процедурные текстуры, свет, тени, гул, шаги и эффекты. Пауза останавливает игровые часы и аудио.

**Русские записи голоса пока отсутствуют.** Подключены система воспроизведения файлов, субтитры и эмоции. Какие записи добавить и как: `public/audio/voice/README.md`. Никакая готовая речевая озвучка не заявляется. Ярость и начало превращения появляются только в комнате с тортом после нажатия кнопки.

## Сюжет и структура

Актуальные требования — `3D_REQUIREMENTS.md`; обновлённый формат — `GAME_DESIGN.md`; полный исходный сюжет — `GAME_DESIGN_ORIGINAL.md`. Реплики находятся в `src/story.js`, правила вступления — в `src/state.js`, новая головоломка — в `src/cake-state.js`, комната — в `src/cake-room.js`, вступительный мир — в `src/world.js`, модель Верити — в `src/verity.js`, управление — в `src/input.js`, столкновения — в `src/physics.js`, звук и диалоги — в соответствующих модулях.

Графика и звуки окружения — собственные временные материалы. Лицо Верити не копирует чужие изображения; коммерческие права на имя/персонажа требуется проверить перед публикацией. Продолжение после комнаты с тортом, ветка «Спасение», погоня, реклама и SDK пока не реализованы. Реальных голосовых файлов нет; подготовлены 14 реплик.

## История и возврат к 2D

Перед переделкой создан локальный Git-репозиторий. Ветка `prototype-2d` сохраняет исходный прототип; версия 0.2 — `feature/3d-horror`; полировка — `feature/visual-audio-polish`; текущая работа — `feature/cake-room`. Чтобы отдельно открыть прежнюю версию без переключения текущих файлов:

```sh
git worktree add ../ne-ver-veriti-2d prototype-2d
```

Публичный репозиторий: https://github.com/vil-h/ne-ver-veriti. На GitHub опубликован текущий 3D-проект в ветке `main`. Ветки `prototype-2d` и `feature/3d-horror` и исходная история сохранены в локальном репозитории разработчика. После клонирования выполните `npm install` и `npm run build`, чтобы создать `dist` для запуска через командный файл.

## Проверки

Итоговые результаты и ограничения проверки перечислены в `TEST_REPORT.md`.

Для диагностики запуска добавьте `?diagnostics=1` к адресу игры: появятся состояние WebGL, видимость страницы, счётчик кадров и ошибки. В обычном запуске эта панель скрыта.
